# 台灣股市線上選股程式

這是一個可直接在瀏覽器使用的台股選股工具，不需要安裝前端框架。

## 功能

- 依股票代號、名稱、產業搜尋
- 開頁即載入完整資料檔，涵蓋上市、上櫃、ETF/ETN
- 依殖利率、本益比、股價淨值比、成交量、股價區間篩選
- 依近一年漲幅、月營收年增率、季營收篩選
- 可一鍵切換近一年漲幅排行
- 內建價值股、存股、強勢股、穩健策略
- 可讀取證交所公開資料
- 可匯入 CSV、匯出篩選結果
- 可建立本機觀察清單

## 使用方式

1. 開啟 `index.html`。
2. 頁面會自動載入 `data/market-data.json` 完整資料。
3. 若要更新資料檔，可執行 `node scripts/build-data.mjs` 從官方資料重新產生。

## CSV 欄位

CSV 欄位名稱可包含：

- 代號
- 名稱
- 市場
- 類型
- 產業
- 價格
- 漲跌幅
- 成交量
- 殖利率
- 本益比
- 股價淨值比
- 近一年漲幅
- 月營收年增率
- 月營收
- 季營收
- 營益率

## 注意

本工具只做資料整理與條件篩選，不構成任何投資建議。
