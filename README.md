# 台灣股市線上選股程式

這是一個可直接在瀏覽器使用的台股選股工具，不需要安裝前端框架。

## 功能

- 依股票代號、名稱、產業搜尋
- 依殖利率、本益比、股價淨值比、成交量、股價區間篩選
- 內建價值股、存股、強勢股、穩健策略
- 可讀取證交所公開資料
- 可匯入 CSV、匯出篩選結果
- 可建立本機觀察清單

## 使用方式

1. 開啟 `index.html`。
2. 點選「更新官方資料」讀取證交所上市股票資料。
3. 若官方資料暫時無法讀取，可先使用內建範例資料，或匯入自己的 CSV。

## CSV 欄位

CSV 欄位名稱可包含：

- 代號
- 名稱
- 產業
- 價格
- 漲跌幅
- 成交量
- 殖利率
- 本益比
- 股價淨值比

## 注意

本工具只做資料整理與條件篩選，不構成任何投資建議。
